ProTomuss

Application de bureau pour consulter les notes de l'Université Lyon 1
Type Logiciel
Date 2020
Pourquoi ?
L'idée derrière ce projet est de repenser entièrement l'interface du site de notes universitaires. L'interface officielle étant mal organisée et peu interactive, le but a été de se rapprocher d'une interface comme pronote. Pour ne pas simplement appliquer un thème au site officiel et avoir une certaine valeur ajoutée au projet, j'ai décidé de créer une application de bureau qui permet donc de s'affranchir du navigateur internet.
L'application organise les notes par matières et les matières par semestre afin de se rapprocher d'une interface comme pronote. Les informations par matières sont aussi triées de facon à séparer les notes, des informations telles que le groupe de travaux pratiques, les dates d'examens etc... ce qui n'est pas le cas sur le site officiel.

Fonctionalités de l'application :
  • Connexion par identifiant de l'univ-lyon1
  • Semestres
  • Matières (UE)
  • Notes (avec statistiques sur la promo)
  • Contact des différents responsables/professeurs d'UE
Comment ?
Le projet est construit avec electron, qui permet d'utiliser les connaissances des langages web pour développer une application de bureau portable. Le but du projet étant de réaliser une intégration HTML/CSS/JS avec des données variées. Ces données sont récupérées sur le site officiel de l'univ-lyon1 avec les identifiants que l'utilisateur fournit sur la page de connexion. L'application est entièrement responsive.
  • Back : Python/NodeJS
    Script python qui permet la connexion au site de l'université par requête http. Les données sont alors triées et récupérées au format JSON et stockées dans un fichier pour pouvoir ensuite être affichées.
  • Front : HTML/CSS/JS
    Traitement des données et séparation des matières par semestres, des notes par matières etc... Affichage des notes et matières selon le semestre selectionné.
Problèmes et Limites
Le site sur lequel l'application est basé ne dépendant pas de moi et étant mis à jour régulièrement, toutes les fonctionnalités existantes sur le site de l'université ne sont pas implémentées dans ce projet. Le problème majeur rencontré sur l'application est le fait que le site officiel bloque les connexions répetitives et restreint par conséquent la mise à jour des données de l'application.
Suite au développement des cours à distance, le site officiel sur lequel est basé ce projet à beaucoup évolué avec de nouvelles fonctionnalités qui interagissent directement avec les serveurs de l'université. Il est donc impossible pour moi d'implémenter ces fonctionnalités dans l'application car je n'ai pas accès aux serveurs universitaires.
