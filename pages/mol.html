Base de données molécules

  • code source : github
  • rapport : pdf

Contexte

Projet réalisé dans le cadre d'un stage à l'Institut Lumière Matière (ILM) à l'Université Lyon 1. Il s'est déroulé sur 7 semaines au sein de l'équipe chimie théorique. J'étais le seul stagiaire sur ce projet et sous la supervision d'un tuteur.

Le projet

Développer des codes pour utiliser une large base de données de molécules, l'extraire, la modifier, effectuer des calculs spécifiques et travailler sur des méthodes machine learning.

Technique

Les codes sont développés en python en utilisant parfois jupyter notebook. Le rapport est fait grâce à latex et certaines figures sont produites avec fga.
