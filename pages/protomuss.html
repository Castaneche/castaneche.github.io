ProTomuss - College's grades

Project #4

Durée

L’apprentissage de Electron et le développement de l’application a duré environ 2 mois.

Mon Role

J’ai travaillé seul sur ce projet. Mes camarades étudiants m’ont permis de pouvoir tester l’application sur les différents comptes et formations de l’université.

But du projet

Le but de ce projet est de pouvoir accéder au notes universitaires sur une interface graphique attirante et directement depuis le bureau windows. Les notes, affichées brutes sur le site officiel, sont ici affichées et classées par matières ainsi que les informations sur les responsables de cours, les groupes de classe ou encore les travaux pratiques. L’application est inspiré de l’application de référence pour les collèges/lycées : pronote.

Approche

  • Le projet étant accentué sur l’amélioration du design du site officiel, l’application est codée avec les languages du Web : HTML, CSS, Javascript ainsi qu'avec l’environnement Electron ce qui a permis d’arriver à un résultat satisfaisant très rapidement et simplement.
  • La partie backend de l’application est réalisée en Python. Un script lancé lors de la connection permet de récupérer les données nécessaires sur le site officiel de l’université.

Défis

  • Le site de L’université ne disposant pas d’API, il a fallu effectuer les actions d’un utilisateur lambda avec un script python (rentrer les identifiants, récupérer les données affichées sur le site). De nombreux problèmes ont été rencontrés pour faire fonctionner ce script car le site est assez ancien et dispose de quelque option anti-bot qu'il a fallu contourner.
