ProTomuss - College's grades

Project #4

Duration

L’apprentissage de Electron et le développement de l’application a duré environ 2 mois.

My Role

J’ai travaillé seul sur ce projet. Mes camarades étudiants m’ont permis de pouvoir tester l’application sur les différents comptes et formations de l’université.

Purpose of the project

Le but de ce projet est de pouvoir accéder au notes universitaires sur une interface graphique attirante et directement depuis le bureau windows. Les notes, affichées brutes sur le site officiel, sont ici affichées et classées par matières ainsi que les informations sur les responsables de cours, les groupes de classe ou encore les travaux pratiques. L’application est inspiré de l’application de référence pour les collèges/lycées : pronote.

Approach

  • Le projet étant accentué sur l’amélioration du design du site officiel l’application est codée avec les languages du Web : HTML, CSS, Javascript avec l’environnement Electron ce qui a permis d’arriver à un résultat satisfaisant très rapidement et simplement.
  • La partie backend de l’application est réalisée en Python. Un script lancé lors de la connection permet par scraping de récupérer les données nécéssaires sur le site officiel de l’Université.

Challenges

  • Le site de L’université ne disposant pas d’API, il a fallu effectuer les actions d’un utilisateur lambda avec un script python (rentrer les identifiants, récupérér les données affichées sur le site). De nombreux problèmes ont été rencontrés pour faire fonctionner ce script.
  • Par soucis de rapidité, l’outil sélénium n’a pas été utilisé. Les requètes http via script étant mal supportées par le site il a fallu user de patience afin de pouvoir arriver a une résultat convaincant et fonctionnel.
