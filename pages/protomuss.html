ProTomuss

Description :

Logiciel pour les étudiants de l'université de Lyon 1. Il permet de se connecter au site des notes universitaires et d'afficher les données de façon plus organisée et attractive que le site officiel.

Type Logiciel
Technologies Electron, NodeJS, HTML, CSS, JavaScript, Python

Contexte

Le site officiel permettant de consulter les notes universitaires est peu attirant visuellement. Dans l’idée d’améliorer l’interface et de pouvoir apprendre de nouvelles technologies j’ai décidé de développer une application de bureau permettant de consulter ses notes directement sur windows sans utiliser de navigateur.

Description

L’application permet d’accéder aux notes universitaires sur une interface graphique attirante et directement depuis le bureau windows. Les notes, affichées brutes sur le site officiel, sont ici affichées et classées par matières ainsi que les informations sur les responsables de cours, les groupes de classe ou encore les travaux pratiques. L’application est inspiré de l’application de référence pour les collèges/lycées : pronote.

Technique (front-end)

L’environnement Electron a été utilisé pour ce projet car il permet de créer des applications de bureau avec les languages du web HTML, CSS, JavaScript. Ce choix est pertinent car il est très facile avec ces languages d’obtenir une interface graphique moderne et c’est le but du projet.

Technique (back-end)

Les données sur le site ne sont pas disponibles facilement (il n’y a pas d’API). Il a fallu donc utiliser un script python et récupérer les données une par une. Pour cela, le script simule les actions de l’utilisateur en faisant des requêtes http. Cela s’est avéré compliqué car le site officiel est généré entièrement en javascript et possède des protections anti bot. Il a fallu donc contourner ces restrictions pour obtenir les données.

Comparaison

On peut voir la partie front du site et celle de l’application. L’interface est plus moderne et mieux organisée.

Limitations

Le site officiel est en constante évolution et depuis la pandémie de Covid beaucoup de nouvelles fonctionnalités pour les cours en lignes sont apparues. Ces fonctionnalitées dépendent des serveurs de l’université et il n’est donc pas possible de les implémenter dans l’application. Cette application est donc obsolète à ce jour.
