Perlin Noise Visualizer

Description :

Logiciel permettant de visualiser en temps réel le bruit de Perlin. Le bruit est généré en 1D 2D et 3D sous forme de graphique, texture ou terrain.

Type Software
Technologies C++
Librairies OpenGl, Dear ImGui
Download v1.2

Contexte

Dans l’idée d’apprendre le rendu 2D et 3D j’ai souhaité réaliser un projet visuel. Comme le bruit de Perlin est un algorithme très répandu mais peu expliqué j’ai donc choisi de réaliser un logiciel permettant de jouer avec les paramètres afin de visualiser les effets.

But du projet

Le but de ce projet est de pouvoir visualiser en plusieurs dimensions un algorithme de génération de bruit cohérent (ici le bruit de Perlin). L’idée est de voir les effets des paramètres de l’algorithme (octaves, fréquence, persistance...) en temps réel et dans trois différentes dimensions (graphique, texture et terrain).

Technique

Le logiciel est codé en C++ et utilise OpenGl pour le rendu graphique. L’interface est construite grâce à la librairie Dear ImGui. Le projet est multithread c’est à dire que chaque action de l’utilisateur sur les paramètres de l’algorithme lance le calcul en parallèle. Cela permet de ne pas bloquer l’application lors de long calculs et aussi de pouvoir visualiser en temps réel les modifications.

Graphique

Le bruit peut être visualisé en une dimension sur un graphique avec en abscisse l’incrément et en ordonnée la valeur du bruit normalisée.

Texture

Il est possible de générer une texture de bruit et de visualiser en temps réel les changements de paramètres de l’algorithme. Ces textures peuvent être exportées en fichier image pour être utilisées dans d’autres logiciels.

Terrain

La texture générée peut être visualisée en 3D (terrain). La texture est appliquée sur un plan avec en chaque point une amplitude liée à la valeur du bruit. L’amplitude peut être modifiée afin d’obtenir de plus grands dénivelés.

Colormap

Une interface permet à l’utilisateur de sélectionner une gamme de couleurs, et de positionner chaque couleur afin d’avoir le rendu de texture attendu. Cette fonctionnalité (non disponible dans les librairies) a été dévelopée spécialement pour ce projet. Ici, on a par exemple un rendu faisant penser à une vue aérienne. On peut voir à gauche l’interface permettant de jouer sur les paramètres de couleur.
