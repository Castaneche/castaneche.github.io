FGA - Fast Graphing & Analysis Software

Description :

Logiciel d'analyse de données. Il permet d'afficher des données sous forme de courbes et de réaliser des opérations tels que l'ajustement, la dérivée, l'intégrale, la transformée de Fourier, etc...

Type Software
Technologies C++
Librairies OpenGl, Dear ImGui, GSL
Download demo version

Contexte

La plupart des logiciels utilisés aujourd'hui dans les universités sont datés et non mis à jours. L'idée de ce projet est donc de fournir une alternative aux logiciels d'analyse de données que j'ai pu utiliser dans mon cursus.

Approche

Toutes les courbes peuvent être glissée et déposée rapidement dans un graphique ou dans les modules d’analyse de cette façon le logiciel est rapide et simple d’utilisation. Toujours dans un but de simplicité, toutes les fonctionnalités sont disponibles directement sur l’interface principale sans chercher dans de multiples sous menus.

Lors du développement, une attention particulière a été portée sur la clarté et l’organisation du code car c’est un projet assez imposant. Cela a permis de développer rapidement et de rajouter des fonctionnalités sans problème (le projet n’est pas open source pour l’instant)

Le logiciel est codé avec des librairies légères et compilé grâce à CMake pour être portable, c’est à dire fonctionnel sur clé usb (par exemple).

Technique

Le logiciel est entièrement codé en C++ et utilise OpenGl pour le rendu graphique. L’interface est réalisée grâce à la librairie Dear ImGui (et ImPlot) que j’apprécie tout particulièrement pour la rapidité et la simplicité du développement. Tout est paramètrable, ce qui a permis de pouvoir obtenir l’apparence que je souhaitais. Pour ce qui est de l’analyse scientifique, le choix s’est porté sur la librairie GSL pour la variété et flexibilité des opérations numériques qu’elle offre.

Style

Chaque courbe possède un style propre. Il peut être modifié pour obtenir le style de courbe voulu. Il y a aussi possibilité d'ajouter des barres d'erreurs en chaque point de la courbe.

Thèmes

Analyse

Plusieurs modules permettent l’analyse numérique des courbes. Il est possible de calculer une dérivée, une intégrale, de faire un ajustement de suivant un modèle donné, d’obtenir le spectre en fréquence par transformée de fourier...

Import & Export

Les données peuvent être générée par le logiciel mais il est aussi possible d'importer des données extérieures stockées dans des fichiers csv ou texte. Le module d'importation / exportation est flexible et permet de choisir certains paramètres (le délimiteur, la direction, les labels...)

Site

Il est prévu de déployer un site pour télécharger ou se renseigner sur le logiciel. Le site n'est pour le moment pas en ligne mais la maquette est déjà créée et fonctionnelle. Il pourra être mis en ligne dès que le logiciel sera terminé.
