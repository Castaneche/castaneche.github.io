Workout Timer

Application pour smartphone donnant accès à un timer spécifique pour les séances de sport.
Type Application
Date 2019
Description
Ayant besoin d'un timer spécial pour mes séances de sport et les applications existantes ne répondant pas à mes besoins, j'ai décidé de créer ma propre application. Cette application fonctionne sous android et permet donc de paramètrer des séances avec un nombre de répétition et un temps de travail variable.

Fonctionnalités :
  • Séance paramètrable avec : nombre de set, temps de travail par set, temps de repos par set.
  • Configurer et sauvegarder des séances.
  • Avertissement sonore lorsque le temps de travail est terminé.
L'application reste très simple pour une rapidité d'utilisation maximum sans se perdre avec la multitude d'options que certaines applications proposent.
Comment ?
L'application est développée avec le moteur Unity qui est plus connu pour son utilité dans le domaine du jeux vidéo. Il a été utilisé ici pour la simplicité du déploiement sous android. Le système UI du moteur étant aussi assez intuitif, Unity a grandement facilité le développement de l'application. La logique de l'application est donc codée avec le language C#.
