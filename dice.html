421 Dice game

Détection en temps réel des faces de dés par lecture caméra.
Type Script
Date 2021
Description
Ce projet s'inscrit dans un projet universitaire ayant pour but de réaliser une acquisition informatisée avec Labview (logiciel d'instrumentation) et le language de programmation Python. Le but du projet était de simuler un jeu de 421 avec des nombres aléatoires représentant les dés. Pour plus d'interactivité, il a été décidé de faire l'acquisition de vrai dés avec une caméra. La lecture caméra se fait par un smartphone qui stream le flux vidéo en wifi directement sur l'ordinateur qui analyse ensuite image par image. On a donc une détection des points sur les faces des dés avec un code couleur permettant de distinguer les dés les uns des autres. Avec le temps et les moyens limités que le projet universitaire disposait, le projet n'a pas été poussé plus loin.

Comment ?
La librairie de traitement d'image OpenCV a été utilisé pour l'analyse du flux vidéo image par image. Différentes étapes sont nécessaires pour ce projet :
  • Passage de l'image en noir et blanc.
  • Sélection des zones blanches selon un critère de taille ou luminosité.
  • Trie des différentes zones blanches trouvées précédemment selon un critère de distance pour déterminer à quel dé elles appartiennent.
  • Affichage des zones trouvées avec des cercles colorés.
