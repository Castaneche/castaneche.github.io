NoiseVisualizer

Logiciel de visualisation en temps réel du bruit de Perlin.
Type Logiciel
Date 2020
Description
L'idée derrière ce projet est de pouvoir visualiser en temps réel l'influence des paramètres régissant le célèbre algorithme de Perlin. Pour cela, les paramètres de l'algorithme sont modifiables avec les boutons et sliders et on obtient en sortie un graphe, une texture, ou un terrain générés en fonctions des paramètres de l'algorithme. Le but est de pouvoir comprendre comment les différents paramètres influencent le bruit.

Le logiciel simule le bruit de Perlin selon 4 paramètres :
  • La graine (seed) du générateur de nombre pseudo-aléatoire.
  • Le nombre d'octave qui correspond au nombre de bruit généré (ces bruits sont ensuite superposés pour donner un seul bruit).
  • La persistence , facteur qui correspond à l'influence de chaque octave sur le bruit final.
  • La fréquence qui se traduit par un zoom.
Il est possible de visualiser le bruit avec différentes dimensions :
  • Graphe 1D
  • Texture 2D : sauvegarde en fichier image (.png) possible.
  • Terrain : le bruit est calculé en deux dimensions mais est visualisé en 3D. Sauvegarde en fichier object (.obj) possible.
Deux thèmes visuels sont disponibles pour l'application : clair ou foncé.
Comment ?
Ce projet est réalisé en C++ qui est langage permettant une flexibilité et une rapidité au niveau de l'algorithme. L'affichage est fait grâce à OpenGl et toute la partie interface fonctionne grâce à dear-imgui.
Le bruit est calculé dans un thread secondaire afin d'avoir une fluidité dans l'exécution du programme et de pouvoir visualiser en temps réel les modifications apportées aux paramètres de l'algorithme.
Le widget permettant la modification des couleurs (n'existant pas dans la librairie dear-imgui) a été implémenté spécialement pour ce projet. Il permet un ajout ou suppression de couleurs ainsi que la possibilité de modifier l'influence de chaque couleur indépendamment.
