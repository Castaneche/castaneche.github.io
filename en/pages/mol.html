Molecules Database

  • source code : github
  • report : pdf

Context

Project carried out as part of an internship at the Institut Lumière Matière (ILM) at the University of Lyon 1. It took place over 7 weeks within the theoretical chemistry team. I was the only trainee on this project and under the supervision of a tutor.

The project

Develop codes to use a large database of molecules, extract it, modify it, perform specific calculations and work on machine learning methods.

Technique

The codes are developed in python sometimes using jupyter notebook. The report is made thanks to latex and some figures are produced with fga.
