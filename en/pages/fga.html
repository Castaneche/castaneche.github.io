FGA - Fast Graphing & Analysis Software

Description :

Data analysis software. It allows you to display data with curves and to perform operations such as fitting, derivative, integral, Fourier transform, etc...

Type Software
Technologies C++
Librairies OpenGl, Dear ImGui, GSL
Download demo version

Context

Most of the softwares used in universities today are outdated. The idea of this project is to provide an alternative to the data analysis software that I used in my studies. This software allows a fast and efficient data analysis and visualization with the possibility to use many scientific tools such as: derivative, integral, fourier transform...

Approach

All curves can be quickly dragged and dropped into a graph or into the analysis modules so that the software is fast and easy to use. Always with the aim of simplicity, all the functionalities are available directly on the main interface without searching into multiple menus.

During development, particular attention was paid to the clarity and organization of the code because it is a rather large project. This allowed to develop quickly and to add features without problems (the project is not open source for the moment)

The software is coded using small libraries and compiled with CMake in order to be portable, i.e. functional on usb key.

Technique

The software is entirely coded in C++ and uses OpenGl for graphical rendering. The interface is made using the Dear ImGui library (and ImPlot) which I particularly like for the speed and simplicity of development. Everything is customizable, which made it possible to get the look I wanted. As for the scientific analysis, the choice fell on the GSL library for the variety and flexibility of numerical operations it offers.

Styling

Each curve has its own style. It can be modified to obtain the desired curve style. It is also possible to add error bars at each point of the curve.

Themes

Analysis

Several modules allow numerical analysis on the curves. It is possible to calculate a derivative, an integral, to make a fit according to a given model, to obtain the frequency spectrum by fourier transform, etc...

Import & Export

The data can be generated by the software but it is also possible to import external data stored in csv or text files. The import/export module is flexible and allows to choose some parameters (delimiter, direction, labels...)

Website

It is planned to deploy a site to download or learn about the software. The site is not online for the moment but the design is already done. It will be put online as soon as the software is finished.
