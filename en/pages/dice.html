Realtime Dice Detection

Description :

Script that connects to a camera to detect in real time the values displayed on the faces of dice.

Type Script
Technologies Python
Librairies OpenCV

Context

During a university project aiming at developing (in group of 2) the 421 game on LabView and Python the idea came to push the project further. As the game is only played on the computer without any real interaction, we decided to find a way to play physically.

The project

This project allows, with a simple camera (smartphone), to detect the numbers displayed on the faces of dice (previously thrown by the player). The program outputs a list with the corresponding numbers.

Technique

The project is a python script using the OpenCV library. The script connects to an IP camera (here a smartphone connected to the local network) and retrieves the video stream in real time to analyse it frame by frame. Each image is scanned to obtain the contours. They then allow to detect the points drawn on the dice and by enumeration to obtain the values associated with each dice.

Process

We can see here an intermediate step of the processing applied to the image. The image is first switched to black and white. The dots being white, it is sufficient to isolate the areas corresponding to circles of a certain size. Finally, the detected areas are assigned to each dice by relative distance test and are counted to obtain the output dice values.

Limitations

The detection of the edges on the image depends on the brightness or the angle of the camera in relation to the dice. That's why this project only works under well-defined conditions: dark background, dice with white dots, camera well aligned above the throwing area.
