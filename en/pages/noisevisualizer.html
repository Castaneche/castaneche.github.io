Perlin Noise Visualizer

Description :

Software to visualize the effect of the parameters of the Perlin noise algorithm. The noise is generated in 1D 2D and 3D as a graph, texture or terrain..

Type Software
Technologies C++
Librairies OpenGl, Dear ImGui
Download v1.2

Context

With the idea of learning 2D and 3D rendering I wanted to realize a visual project. As the Perlin noise is a very common algorithm but not very well explained, I chose to create a software allowing to play with the parameters in order to visualize the effects.

Purpose of the project

The goal of this project is to be able to visualize in several dimensions a coherent noise generation algorithm (here the Perlin noise). The idea is to see the effects of the algorithm's parameters (octaves, frequency, persistence...) in real time and in three different dimensions (graph, texture and terrain).

Technique

The software is coded in C++ and uses OpenGl for the graphic rendering. The interface is built with the Dear ImGui library. The project is multithreaded, which means that each action of the user on the algorithm's parameters launches the calculation in parallel. This allows not to block the application during long calculations and also to be able to visualize in real time the modifications.

Graph

The noise can be visualized in one dimension on a graph with the time on the horizontal axis and the normalized noise value on the vertical axis.

Texture

It is possible to generate a noise texture and to visualize in real time the changes of the algorithm parameters. These textures can be exported as image files to be used in other software.

Terrain

The generated texture can be visualized in 3D (terrain). The texture is applied on a plane with an amplitude associated to the noise value at each point. The amplitude can be modified in order to obtain larger gradients.

Colormap

An interface allows the user to select a range of colors, and to position each color in order to have the expected texture rendering. This feature (not available in the libraries) was developed especially for this project. Here we have for example a rendering that looks like a bird's eye view. You can see on the left the interface to play with the color settings.
