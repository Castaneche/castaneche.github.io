Minimisation

Context

During my scientific studies, I worked on numerical analysis : fitting, derivative, minimization, differential equations, analysis... Several projects were proposed and I chose to work on the problem of the travelling salesman which is a recurrent problem in computer science.

The project

The goal was to minimise the travel time of a tree of N points placed on a two dimensional space. The points represent the cities that the traveler must cross and the space between the points the distance between the cities. No starting point was imposed, the goal was to test three methods: naive, simulated annealing and genetic.

Technique

The ROOT library developed by CERN was imposed in order to get familiar with the tools used by the scientists. The project has been developed in C++ and the display is done with ROOT.

Naive method

This method explores all possible paths and keep the shortest one. It allows to find the minimum in all cases but the computation time can become very high when the number of points to be covered increases.

Simulated annealing

This method makes the analogy with the cooling of a physical system. When a system is hot, its matter is very agitated and the more it cools the more the agitation decreases towards a minimum of energy. By using this analogy, we try to solve the travelling salesman problem. We start from a random path then we permute the route with a certain probability keeping the shortest path at each step. At the beginning the probability is great so the path is brought to change very strongly then during the time the probability of change decreases and the path is refined until obtaining the shortest path.

Cette méthode a bien fonctionné pour notre problème car il est possible d’augmenter le nombre de points à parcourir sans augmenter le temps de calcul de façon exponentiel. Cette méthode est donc bien meilleure que la précédente.

Genetic method

This time, the analogy is made using natural selection. We take a population of random paths and apply a series of permutations. We then perform a selection on the starting population by taking the interesting paths, then repeat the procedure. This method did not work as expected and was therefore abandoned because we could only find the minimum for a small number of points to cover.
